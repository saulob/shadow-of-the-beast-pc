Shadow of the Beast PC Port
===========================

This package contains the port's launcher and runtime only. It contains no game files.

Bring your own legally obtained, decrypted PS4 package of Shadow of the Beast (CUSA03762 Korea, CUSA02871 USA or CUSA00951 Europe).

Run shadow_of_the_beast.exe, open the Play page, choose Install game..., and select the .pkg.
The game is unpacked into the game folder next to the program.

Settings and saves live in user\; logs live in logs\.

trg-updater.exe installs launcher updates after you choose UPDATE NOW; keep it beside the program.
